# 《台北劇本殺物語 3D》原始美術問題盤點報告 (Art Audit)

> 盤點時間：2026-10-21  
> 審查專案：`taipei-larp-3d` (`public/game3d.js`, `public/index.html`)  
> 基準版本：v2.0-upgrade

---

## 1. 實際專案技術與引擎現狀

- **3D 引擎**：Three.js `r128` (`public/lib/three.min.js`, 603 KB)，採用 WebGLRenderer，搭配 OrbitControls 控制器。
- **建模來源**：完全由程式碼於執行期進行程序化幾何體（Procedural Low-Poly）生成，不依賴外部龐大 GLTF/FBX 檔案，具備首屏零延遲加載優勢。
- **貼圖與材質來源**：
  - 材質使用 `MeshStandardMaterial` 與 `MeshBasicMaterial`。
  - 招牌文字透過 HTML5 2D Canvas 動態渲染生成 CanvasTexture 貼圖。
- **光源與陰影現狀**：
  - 單一方向光 `DirectionalLight` 投射陰影（2048x2048 PCFSoftShadowMap）。
  - 環境光 `AmbientLight` 與半球光 `HemisphereLight` 提供基底補光。
  - 自建 Procedural 漸層接觸陰影面片（Contact Shadows）。
- **攝影機與透視**：
  - `PerspectiveCamera` (FOV: 34)，固定於 45 度等角（Isometric）微縮模型視角。

## 2. 原始美術核心問題盤點 (7 大優先痛點)

| 優先序 | 盤點項目 | 現狀痛點分析 | 改善方向與具體作法 |
|---|---|---|---|
| **P1** | **建築比例與街道尺度** | 過去背景大樓過於方正，門窗與人物比例未達嚴格的 1m 建築基準。 | 確立場景尺度標準：1 單位 = 1 公尺；人高 1.75m，樓高 3.2m，騎樓淨高 3.0m，門高 2.4m，車道寬 10m。 |
| **P2** | **建築立面與材質單一** | 街區部分立面仍為單純方塊，缺乏材質細緻度差異，磁磚、玻璃與混凝土無明顯質感區隔。 | 引入多種立面模組變體（老台北洗石子、紅色二丁掛磁磚、現代玻璃帷幕、水泥拉毛），深開窗配以金屬窗框與玻璃反射。 |
| **P3** | **店家入口與招牌層次** | 店家入口已具備騎樓與直立招牌，但細節深度仍可提升；缺少店門玻璃反光、營業燈箱與特色陳設。 | 精雕 14 家名店專屬門面風格；加入鐵捲門軌、門頭橫匾、騎樓圓形投光燈與層疊外凸小招牌。 |
| **P4** | **光影與色彩分級缺乏層次** | 原本只有日夜兩態切換，白天的光照過硬、黃昏色彩過渡平淡、夜晚背景雖暗但店內溢光不足。 | 建立三段式精確日夜色彩調光系統：清晨白天自然散射天光、黃昏 3000K 暖橙暮色紫霞、深夜深邃藍黑底色配高對比璀璨自發光。 |
| **P5** | **玩家角色與 NPC 造型** | 角色為基礎 Box 組合，頭身比略顯積木化（1:3），手腳未分節，服裝無厚度。 | 重塑精緻風格化角色模型（1:5.5 自然優雅頭身比），具備獨立髮型輪廓、立體外套肩線、鞋底厚度與配件背包。 |
| **P6** | **道路與市井環境細節** | 馬路邊緣缺乏更豐富的台北元素，人行道交接處平整，路面反光與質感可再強化。 | 鋪設人行道導盲磚紋理、斑馬線磨損細節、路緣黃紅漆線、更多機車停放格、消火栓與郵筒。 |
| **P7** | **店家室內空間層次** | 目前室內僅有圍讀長桌與椅子，缺乏接待櫃檯、劇本陳列展示架、候位沙發與主題氛圍光源。 | 升級旗艦店家室內空間：新增玄關櫃檯、立體書櫃牆擺滿數十本劇本模型、溫暖吊燈與柔和地毯。 |

## 3. 資產分類與盤點清單

### 🟢 已有資產（可沿用並優化）
1. `public/game3d.js`：核心遊戲循環、相機動畫控制、存檔遷移系統。
2. 14 家台北真實店家資料庫與坐標資料（`gamedata.json`）。
3. 98 位主持人與 15 位車友社交關係資料（`peopledata.json`）。
4. 8-Bit Web Audio 音效合成器（無外部音檔依賴）。

### 🟡 可改善資產（重構升級）
1. **建築生成器**：由單純 Box 改為多樣化模組（騎樓、二丁掛磁磚、遮雨棚、鐵窗花、頂加鐵皮）。
2. **光照系統**：日夜循環計算公式，增加微醺懸疑色彩分級與各時段專屬色溫。
3. **角色建模**：玩家主角與 NPC 網格階層重塑。
4. **店家室內空間**：長桌周圍加入精緻櫃檯、書架與陳列道具。

### 🔴 需新增資產
1. `docs/ART_SPECIFICATION.md`：美術風格規範文件。
2. 3D 台北郵筒（綠色普通/紅色航空）、消火栓、人行道反光防撞桿。
3. 劇本殺專屬室內書架道具與立體劇本盒模型。
